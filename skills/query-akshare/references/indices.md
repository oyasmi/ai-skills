# 指数与基准

## 为什么单列

"相对沪深300 表现如何"是最常见的追问。指数与个股、基金的口径不同：指数是点位，不复权、不含分红，编制规则由指数公司定义；用它当基准时必须说明这一点。

## 标准链路

```text
指数代码确认 → 指数历史点位 → 与标的按共同交易日对齐 → 报告基准口径
```

常用接口：

```text
index_zh_a_hist
index_zh_a_hist_min_em
stock_zh_index_spot_em
stock_zh_index_daily
stock_zh_index_daily_em
index_hist_csindex
index_stock_cons
index_stock_info
```

代码格式在不同来源之间不一致：东财/中证常用纯六位（`000300`），新浪常用带交易所前缀（`sh000300`）。按 `akqry describe` 的参数说明传入，不要自行拼前缀；不确定时先 `--probe`。

```bash
akqry describe index_zh_a_hist --json
akqry describe index_zh_a_hist --probe --arg symbol=000300 --json
```

## 常用基准代码

`000300` 沪深300、`000905` 中证500、`000852` 中证1000、`000001` 上证指数、`399006` 创业板指、`000688` 科创50。这些是常见约定，仍需用 `stock_zh_index_spot_em` 或 `index_stock_info` 核对名称与来源，代码在不同体系下可能指向不同标的（例如 `000001` 既是上证指数也是平安银行的股票代码）。

## 口径要求

- 指数点位是**不复权、不含分红**的价格指数。除非明确使用全收益指数（如中证全收益系列），不要把指数涨幅当作"持有基准的总收益"。
- 全收益指数与价格指数不能混用在同一条对比中。
- 指数成份与权重是当前快照；`index_stock_cons` 不能回填到历史归因，否则构成幸存者偏差。
- 与个股/ETF 对比时，标的用前复权价格、基准用点位是可接受的近似，但必须写明"标的为前复权价格收益、基准为价格指数收益，均不含分红"。
- 指数与 ETF 不是同一件事：ETF 有跟踪误差、折溢价和费率。比较时说明用的是指数点位还是 ETF 二级市场价格。

## 与标的对齐

指数和个股的交易日基本一致，但停牌会让个股缺日。按共同交易日内连接，并报告丢弃的日期数（见 [analysis.md](analysis.md) 的 `alignment_report`）。
